# AI Recruitment Automation Platform 

An industry-level AI-powered recruitment automation system built using 

This platform automates the complete candidate screening workflow by extracting resume data, analyzing candidate skills using AI, generating ATS scores, and storing structured recruitment insights automatically.

---

##  Features

- Automated Resume Upload Handling
- Dynamic PDF Resume Processing
- Resume Text Extraction
- AI-Based Resume Analysis using Gemini AI
- ATS Score Generation
- Skill Extraction & Missing Skill Detection
- Candidate Recommendation System
- Structured Data Storage in Google Sheets
- Fully Automated n8n Workflow
- Scalable Recruitment Pipeline

---

##  Workflow Architecture

```text
Google Form Submission
        ↓
Google Sheets Trigger
        ↓
Google Drive Resume Download
        ↓
PDF Text Extraction
        ↓
Gemini AI Resume Analysis
        ↓
ATS Score & Skill Evaluation
        ↓
Structured Candidate Data Storage
```
